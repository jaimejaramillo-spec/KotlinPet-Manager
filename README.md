Descripción de la Aplicación
KotlinPet Manager es una aplicación móvil desarrollada en Android y Jetpack Compose, orientada a la gestión y registro de pacientes en una clínica veterinaria.

Características Principales:
* Arquitectura MVVM: Separación clara entre el modelo de datos ("Paciente"), la lógica de negocio ("PacienteViewModel") y la interfaz de usuario ("PacienteScreen").
* Formulario Adaptativo: Registro estructurado con campos independientes para especie, raza, edad y contacto de emergencia.
* Priorización de Urgencias: Clasificación visual destacada para pacientes que requieren atención inmediata.
* Identificación Temporal: Generación automática de estampa de fecha y hora de ingreso para cada registro.
* Gestión Activa: Funcionalidad para eliminar registros individuales.
* Soporte Técnico: Tarjeta integrada con canales de atención al usuario.
